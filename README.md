# scPlant
PhytoCluster is an unsupervised deep learning framework , for clustering scRNA-seq data by extracting latent features.
![24071c7bdb516c46692b03f306c624b](https://github.com/user-attachments/assets/14e6e5cc-0290-4249-a75a-7f8d073ea0ac)


## System requirements
Python 3.10 / 3.11.

Optional: Hardware accelerator supporting PyTorch.
## Install Cropformer

We provided a pre-packaged Conda environment for directly running Cropformer.

```bash
conda env create -f PhytoCluster.yml
```

## Run PhytoCluster
We provide jupyter guides for running PhytoCluster.

In jupyter, you just replace the input file.

Test files can be downloaded directly by the user
